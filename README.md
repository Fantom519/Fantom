### 💻 Các dự án & Nghiên cứu nổi bật

**Hệ thống & Mạng (System & Networking)**
- **Triển khai kiến trúc Zero Trust:** Thiết lập bảo mật mạng với Cloudflare Tunnel, WARP client, Access policies và Gateway filtering.
- **Quản trị Windows Server & Linux:** Xây dựng Active Directory Domain Controllers, cấu hình phân quyền thư mục chéo trên các máy ảo và triển khai kịch bản Bash Shell trên Ubuntu.
- **Mô phỏng mạng Cisco:** Thiết kế topology với OSPF, VLANs, Router-on-a-Stick, ACLs và NAT/PAT.
- **Nghiên cứu khác:** Triển khai OpenWrt trên thiết bị TP-Link & Kỹ thuật Load Balancing (Cân bằng tải) quản lý tài nguyên Cloud.

**Phát triển phần mềm (Software Development)**
- **Ứng dụng Chat Desktop (C# WinForms):** Xây dựng ứng dụng giao tiếp thời gian thực, tích hợp xác thực dữ liệu qua Firebase Firestore và tính năng gọi video/audio với Agora API.
- **Phát triển Mobile (Android):** Xây dựng ứng dụng Android sử dụng Android Studio, Kotlin và tối ưu hóa UI/UX.
- **Cơ sở dữ liệu:** Thiết kế ERD, viết triggers, tối ưu hóa truy vấn và chuẩn hóa dữ liệu (normalization) trên hệ quản trị Microsoft SQL Server.
